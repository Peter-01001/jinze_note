    论文¶

    论文参与程度¶

    这篇论文主要是利用无人机影响检测水稻中的杂草————野慈姑，并进一步区分杂草的单株和多株两种聚集状态。我是该篇论文的第一作者，主要负责数据的处理、模型的设计与实现、实验验证和结果分析以及论文的撰写工作

    为什么要做这个课题？¶

    野慈姑是水稻田中比较常见的杂草，会争夺水稻的生长资源，现有的研究更多关注杂草的检测和分类。而单株和多株的杂草对应杂草的密度以及处理方式都是不同的，因此如果能进一步区分杂草的聚集状态，对后续精准喷药和机械除草等操作都有重要意义

    论文主要使用了什么研究方法？¶

    主要采用深度学习的两阶段识别方法，第一阶段使用yolov8n对无人机遥感影像中的野慈姑进行目标检测，得到目标位置、置信度和初始类别，第二阶段使用patch classification，将检测框中的目标裁剪出来，再专门进行单株和多株的细粒度分类

    为什么你们要采用“两阶段”的方法，而不是直接用 YOLOv8n 完成 single 和 multiple 的识别？¶

    因为要检测区分野慈姑单株和多株的聚集状态，这两种状态是同一类杂草的细粒度区分。yolo模型还需要兼顾定位，所以我们增加第二阶段patch classification对yolo模型检出的目标区域进行单株和多株的分类

    你的数据有多少？从哪里来的？¶

    辽宁省营口实际水稻田拍摄，3307张原始无人机影像，切成11592张640*640的图像，人工筛选出2000张图像构建数据集。训练集、数据集、验证集的划分为1400：300：300

    创新点¶

    • 不仅仅是检测是否有野慈姑，还将其进行单株多株的细粒度分类
    • 在两阶段框架中保持YOLOv8n检测器不变，针对第二阶段分类网络进行了改进，在ResNet18基础上加入MLF多层级特征融合(融合ResNet18的layer2、layer3和layer4特征，让模型同时利用叶片细节、局部结构和高层语义信息)、多尺度局部增强(在layer4使用1×1、3×3和5×5卷积，从不同范围提取叶片重叠、粘连和聚集结构)和ECA通道注意力(对不同特征通道进行加权，让模型更关注对single和multiple分类有用的特征，减少背景干扰)，让模型更关注叶片重叠、粘连和聚集这些结构信息
    • 在评价上不仅看人工标注框下的分类结果，还分别做了预测框评价和完整系统评价，把漏检、误检、定位误差这些实际问题都考虑进去了

    论文的 baseline 是什么？¶

    如果从完整两阶段系统来看，baseline 是 YOLOv8n；如果单独看第二阶段 Patch Classification 的改进，baseline 是普通 ResNet18

    你的方法相比 baseline 有什么提升¶

    我们这篇论文主要针对 YOLOv8n 在 single 和 multiple 两种野慈姑状态之间容易出现类别混淆的问题，引入第二阶段 Patch Classification 做进一步细粒度纠错

    研究过程中问题及解决方法¶

    野慈姑的单株和多株本就是一个物种的不同空间聚集状态，颜色、纹理都相似只靠普通的高层语义特征很难进行分类。第二阶段patch classification网络专注细粒度分类。

    数据类别不平衡，multiple 样本明显更少。通过数据增强提高训练样本的多样性，在评价时也没有只看 Accuracy，而是重点关注 Macro-F1、multiple Recall 和 multiple F1。

    比赛¶

    数学建模¶

    你在数学建模比赛中主要负责什么？¶

    一个中老年人高血脂风险预警和干预优化的问题，关键指标筛选，到风险预测，再到干预方案优化。 我在团队里主要担任编程手，负责把建模思路转化成实际可运行的程序。主要工作包括前期的数据处理、各部分模型的代码实现、模型结果的验证和分析，以及最后的结果整理和可视化。在比赛过程中，我也会根据程序运行结果和队友一起调整建模方案，保证最终模型能够正常求解并得到比较稳定的结果

    用什么方法解决问题¶

    第一问主要是做指标筛选。因为数据里有很多指标，比如血脂、血尿酸、BMI、活动能力等，我们需要判断哪些指标更重要。所以我们分别用==回归模型（Elastic Net）==和==随机森林==分析各个指标的重要程度，再通过重复抽样验证筛选结果是不是稳定

    第二问主要是做风险预测。我们把第一问得到的信息进一步组合起来，用 ==Logistic回归== 计算每个人患高血脂的风险概率

    第三问主要是给出干预方案，使用 ==动态规划算法==

    困难解决办法¶

    我遇到比较大的困难是在第三问。因为要连续优化六个月，每个月都有很多种活动强度和训练频次组合，如果直接全部枚举，搜索空间会比较大。后来我们把它转化成动态规划问题解决

    计算机设计大赛¶

    你在计算机设计大赛比赛中主要负责什么？¶

    我在这个项目中主要负责三个方面的工作：数据处理、小区划分和数据整合

    第一是数据处理，主要是对无人机采集的遥感影像以及一些田间数据进行整理和预处理，为后续分析做准备

    第二是小区划分，就是根据育种试验田的小区边界，把整幅遥感影像划分成一个个对应的育种小区，方便后续针对每个小区单独提取数据

    第三是数据整合，就是把遥感影像中提取出来的数据和人工采集的田间数据，按照小区编号一一对应起来，最后形成统一的数据，提供给后面的可视化和分析模块使用
