## 基础知识

### 分类（classification）

给定一个目标图像或目标区域的情况下，判断它属于哪个类别

### 目标检测（object detection）

不仅要判断目标属于什么类别，还需要预测目标在图像中的位置，也就是 bounding box

> 定位 localization + 分类 classification 一阶段并行 二阶段串行

### Bounding Box（BBox，边界框）：目标检测里用来框住物体的矩形

两种主流格式：

1. xyxy（角点格式，PASCAL‑VOC、Faster‑RCNN、OpenCV）
[x1, y1, x2, y2]
x1,y1：左上角坐标
x2,y2：右下角坐标
适合画图、计算 IoU。
1. xywh 两类变体，考试极易混淆
1）COCO 格式：左上角 + 宽高 [xₘᵢₙ, yₘᵢₙ, w, h]
xmin,ymin 是左上角；w 框宽度，h 框高度。右下角：xmin+w，ymin+h。
2）YOLO 格式：中心点 + 宽高 [cx, cy, w, h]
cx,cy：边界框中心点
w,h：框宽、框高
YOLO 训练用归一化版本：所有值除以图片宽高，取值 0~1。

### 神经网络训练，本质上是在不断调整“参数”

### ResNet18

一种卷积神经网络CNN的经典结构，主要用来做图像分类（残差网络）

> 一个专门看图片并提取特征的神经网络

### CNN（卷积神经网络）

用卷积操作逐层提取图像特征的神经网络

### 卷积

用卷积核在滑动计算图像的特征，得到特征图，进入 CNN 后，“通道”就不再表示红绿蓝了，而变成了模型提取出来的不同特征响应

#### 为什么同时用1×1、3×3、5×5卷积核

不同大小的卷积核能看到不同范围的局部结构（信息范围大小不同）

+ 1×1 卷积：几乎不看周围空间，主要做通道上的特征变换和压缩/映射
+ 3×3 卷积：看一个比较小的局部区域，适合捕捉叶片边缘、局部重叠
+ 5×5 卷积：看更大范围，适合观察更宽的叶片粘连、聚集结构和多个生长中心之间的关系

### feature map（特征图）

卷积层提取出来的一张“特征响应图

### 卷积核 kernel

作用在某一个输入通道上的 \(k\times k\) 权重矩阵

### 卷积滤波器 filter

为了生成一个输出通道，跨越所有输入通道的一整组 kernel

#### filter“学会”某种特征

>图片 → 网络 → 得到预测 → 和真实标签比较 → 算Loss → 反向传播 → 修改filter里的权重

### ResNet

残差网络（Residual Network），通过引入残差连接解决深层网络训练困难的问题

它本质上还是 CNN，只是解决了一个问题：网络变深以后，不一定更容易训练，反而可能出现梯度消失、性能退化
