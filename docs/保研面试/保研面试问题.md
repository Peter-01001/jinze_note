# 面试

## 论文

### 论文参与程度

这篇论文主要是利用无人机影响检测水稻中的杂草————野慈姑，并进一步区分杂草的单株和多株两种聚集状态。我是该篇论文的第一作者，主要负责数据的处理、模型的设计与实现、实验验证和结果分析以及论文的撰写工作

### 为什么要做这个课题？

野慈姑是水稻田中比较常见的杂草，会争夺水稻的生长资源，现有的研究更多关注杂草的检测和分类。而单株和多株的杂草对应杂草的密度以及处理方式都是不同的，因此如果能进一步区分杂草的聚集状态，对后续精准喷药和机械除草等操作都有重要意义

### 为什么你们要采用“两阶段”的方法，而不是直接用 YOLOv8n 完成 single 和 multiple 的识别？

因为要检测区分野慈姑单株和多株的聚集状态，这两种状态是同一类杂草的细粒度区分。yolo模型还需要兼顾定位，所以我们增加第二阶段patch classification对yolo模型检出的目标区域进行单株和多株的分类
