| 指标 | 最通俗的理解 | 为什么这个项目需要它 |
|---|---|---|
| **Precision，精确率** | 电脑圈出来的沟渠，多少是真的？ | 防止把道路、田块误认成沟渠 |
| **Recall，召回率** | 实际存在的沟渠，电脑找出了多少？ | 防止沟渠漏检、断断续续 |
| **IoU，交并比** | 电脑圈的沟渠与人工标注，重合得有多好？ | 同时考虑误认和遗漏，适合评价分割 |
| **mIoU** | 先给每一类算IoU，再取平均 | 综合评价模型，同时照顾支渠等小类别 |
| **OA，总体准确率** | 所有点里，一共判断对了多少？ | 看整体表现，但单独看它容易误判 |
| **mAcc** | 每类分别算“找回多少”，再取平均 | 防止模型只擅长树木、田块，却忽略沟渠 |
| **F1** | 精确率与召回率的综合成绩 | 避免一个高、另一个很低 |
| **混淆矩阵** | 一张“错题分类表” | 看沟渠究竟被错分成了背景、道路还是田块 |
