# 点云语义分割：评价指标基础

## 1. 什么是语义分割？

**给点云中的每个点分配一个类别**，例如沟渠、地面、植被。

- **真实标签**：人工标注的参考类别。
- **预测标签**：模型判断的类别。
- **评价指标**：比较预测标签与真实标签，衡量模型分得好不好。

## 2. 正类与负类

以识别沟渠为例：

- **正类**：关注的类别，也就是沟渠。
- **负类**：其他类别，也就是非沟渠。

> “正、负”表示类别，“对、错”表示预测是否正确。

## 3. TP、FP、FN、TN 与混淆矩阵

**混淆矩阵**是把真实类别与预测类别放在一起比较的表格。

| 真实 ＼ 预测 | 预测为沟渠 | 预测为非沟渠 |
| --- | --- | --- |
| 真实是沟渠 | **TP：找对** | **FN：漏检** |
| 真实是非沟渠 | **FP：误报** | **TN：正确排除** |

例如：把地面当成沟渠是 **FP**；没认出真正的沟渠是 **FN**。

## 4. 常用评价指标

| 指标 | 基本含义 | 公式 |
| --- | --- | --- |
| **Precision（精确率）** | 预测为沟渠的点中，有多少是真的 | TP / (TP + FP) |
| **Recall（召回率）** | 真实沟渠点中，有多少被找到了 | TP / (TP + FN) |
| **F1** | 综合考虑精确率和召回率 | 2TP / (2TP + FP + FN) |
| **IoU（交并比）** | 预测与真实的重合程度 | TP / (TP + FP + FN) |
| **Accuracy（准确率）** | 全部点中，分类正确的比例 | (TP + TN) / 总点数 |

这些指标通常越大越好。**精确率与准确率是两个不同的指标。**

### IoU 怎么理解？

![TP、FP、FN 与 IoU 记忆图](指标示意图.svg)

**中间是找对，左边是漏检，右边是误报；IoU 就是中间占整体的比例。**

## 5. 多类别分割中的常见名称

| 名称 | 含义 |
| --- | --- |
| **OA** | 总体准确率，即所有点中分类正确的比例 |
| **per-class IoU** | 每个类别分别计算的 IoU |
| **mIoU** | 各类别 IoU 的平均值，语义分割常用指标 |
| **mAcc** | 通常指各类别召回率的平均值 |
| **Macro-F1** | 各类别 F1 的平均值 |

> **不要只看准确率。** 如果大部分点都是地面，即使模型认不出沟渠，也可能有很高的准确率。还要看沟渠本身的 IoU 和 Recall。

## 6. 其他常见指标

- **mAP**：目标检测常用指标，用于评价目标是否被正确检测出来，与语义分割的 mIoU 不同。
- **MAE（平均绝对误差）**：预测数值与真实数值，平均相差多少。
- **RMSE（均方根误差）**：也是衡量数值误差，但对较大的误差更敏感。

MAE、RMSE 可用于评价沟渠宽度、深度等测量结果，**越小越好**。

## 7. 记忆口诀

**TP 找对，FP 误报，FN 漏检，TN 正确排除。**

**查准看 Precision，查全看 Recall，重合看 IoU，整体看 mIoU。**

## UAV 图像（无人机遥感影像）

**UAV（Unmanned Aerial Vehicle）**：无人驾驶航空器，即无人机。

**UAV 图像（UAV Images）**：利用无人机搭载的成像传感器获取的遥感影像，具有空间分辨率高、采集灵活等特点，广泛应用于精准农业、环境监测和地物识别。

### 主要类型

- **RGB 图像**：包含红、绿、蓝三个通道，主要提供颜色、纹理和形状信息，用于作物识别、杂草检测等。
- **多光谱图像（Multispectral Images）**：采集多个特定光谱波段，可计算 NDVI 等植被指数，用于作物长势和营养状况监测。
- **高光谱图像（Hyperspectral Images）**：包含大量连续或近连续的窄光谱波段，能够提供更精细的光谱特征，用于作物分类和生理状态分析。
- **热红外图像（Thermal Infrared Images）**：利用热辐射信息分析地表温度，常用于作物水分胁迫和灌溉监测。

### 与 LiDAR 点云的区别

| 对比维度 | UAV 图像 | LiDAR 点云 |
|---|---|---|
| 数据结构 | 二维栅格（像素） | 三维点集（XYZ） |
| 主要特征 | 颜色、纹理、光谱 | 空间位置、几何结构、高度 |
| 常用模型 | YOLO、U-Net、DeepLab | PointNet++、KPConv、RandLA-Net |
| 典型应用 | 作物识别、杂草检测 | 沟渠分割、道路识别、三维测量 |

**注意：** UAV 是数据采集平台，而非数据类型。无人机既可以搭载相机获取二维遥感图像，也可以搭载 LiDAR 获取三维点云。

## NDVI（归一化植被指数）

**NDVI（Normalized Difference Vegetation Index）**：归一化植被指数，是利用植被对红光和近红外光的不同反射特性，评估植被覆盖程度及生长状况的常用遥感指标。

### 计算公式

$$
NDVI = \frac{NIR - Red}{NIR + Red}
$$

- **NIR（Near-Infrared）**：近红外波段反射率。
- **Red**：红光波段反射率。

**计算原理：** 健康植被的叶绿素通常强烈吸收红光，而叶片内部结构对近红外光具有较强的反射作用，因此健康植被通常具有较高的 NDVI 值。

### NDVI 数值含义

NDVI 理论范围为 **-1～1**。

| NDVI 范围 | 一般含义 |
|---|---|
| < 0 | 水体、积雪等非植被地物 |
| 0～0.2 | 裸土、建筑物或稀疏植被 |
| 0.2～0.5 | 中低覆盖度植被 |
| 0.5～1.0 | 较高覆盖度或生长旺盛的植被 |

注：上述区间仅为经验参考，具体解释受植被类型、生育期、土壤背景等因素影响。

### 农业应用

- **作物长势监测**：分析不同区域植被生长状况。
- **植被覆盖度评估**：反映农田植被覆盖程度。
- **作物健康监测**：辅助识别可能存在水分、养分胁迫的区域。
- **精准农业管理**：为变量施肥、灌溉决策提供参考。

**注意：** NDVI 需要红光和近红外波段数据，普通 RGB 图像无法直接计算标准 NDVI；NDVI 也不能单独准确判断作物的具体缺氮量或施肥量。
